Amazon India – Sales & Operations Dashboard (2025)

This project focuses on analyzing Amazon India’s sales and operational performance for 2025 using Microsoft Excel. The goal was to build an interactive dashboard that helps understand sales trends, customer purchasing behavior, payment preferences, delivery performance, and regional revenue distribution.

The dashboard was created using Pivot Tables, slicers, KPI cards, and charts to make the analysis easy to explore and understand. Different filters were added so users can interact with the data dynamically based on month, payment method, and delivery status.

Tools Used
Microsoft Excel, Pivot Tables, Pivot Charts, Slicers, KPI Cards

Key Metrics
Total Orders, Revenue, Customers, Average Order Value, Delivered Orders, Delivery Success Rate

Dashboard Features
Monthly sales trends, category-wise revenue analysis, payment method insights, top-performing states, delivery tracking, interactive filters

Key Findings
Sales showed steady growth in later months
Electronics and Beauty generated the highest revenue
Delivery success rate was relatively low
Digital payments slightly outperformed Cash on Delivery
Revenue was concentrated in a few major states

Project Outcome
            This project helped improve my understanding of data cleaning, dashboard design, KPI reporting, and business-oriented data analysis using Excel.
It also strengthened my ability to convert raw sales data into meaningful insights for decision-making.
